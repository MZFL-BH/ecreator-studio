# 04 发布分发与数据复盘指南

## 一、 核心发布平台差异化文案规范

| 平台 | 标题风格 | 封面与正文侧重点 | 核心流量密码 |
| :--- | :--- | :--- | :--- |
| **小红书** | 口语化 + 情绪痛点 + 关键词（带表情符号） | 封面大字报突出痛点；正文必须分段并带序号，附带 3~5 个精准热门标签 | 搜素权重极高，正文多埋关键词 |
| **B站 (Bilibili)** | 深度好物/硬核拆解/故事悬念型长标题 | 封面突出人物反差表情或核心视觉冲击点；置顶评论引导长篇讨论 | 完播率与弹幕密度（互动率） |
| **视频号 / 抖音** | 结论前置 + 黄金 3 秒强冲突反差短标题 | 竖版满屏视觉；前 2 秒必须出现核心动作或大字幕提问 | 完播率与即时转发率 |

## 二、 完播率与漏斗健康度诊断表

| 诊断指标 | 危险阈值 | 核心问题归因 | 针对性优化动作 |
| :--- | :--- | :--- | :--- |
| **前 2 秒跳出率** | > 40% | 开头拖泥带水，视觉信息过弱，封面与开头内容不符 | 砍掉片头一切打招呼废话，开头即扔结论或反问 |
| **5 秒完播率** | < 25% | 核心吸引点交代太慢，节奏拖沓 | 加快前段剪辑节奏，每 2~3 秒切换一次景别或文字动效 |
| **平均停留时长** | < 视频总长 30% | 中段内容注水，说教感太重，缺少情绪起伏 | 中段增加真实翻车案例或反常识对比作为二段钩子 |
| **互动点赞比** | < 3% | 纯娱乐看完即走，缺少“利他”收藏价值或吐槽共鸣点 | 结尾必须明确指引单一互动动作（如“扣 1 领资料”、“你怎么看在评论区聊聊”） |

## 四、 自动化分发与封面规范（接入 video-publisher）
为打通 Step 04 多平台分发并避免封面裁切报错、手误点到正式发布，分发管线遵循以下硬门禁：
1. **标准分发包**：由 `scripts/generate_script.py` 同步导出 `video_publisher_package.json`，统一承载各平台差异化标题、描述（抖音简介禁止内联 `#标签`，改放 `douyinTopics`）、标签与多比例封面路径。
2. **严格多比例封面矩阵**：
   - **小红书**：仅需 `3:4` 竖版封面（`vertical3x4Path`）；标题按加权长度规则严格控制在 `≤ 20`（中文/全角=1，ASCII=0.5）。
   - **抖音 / 微信视频号**：需同时提供 `3:4` 竖版与 `4:3` 横版双封面；抖音标题严格 `≤ 30` 字符。
   - **B站**：首页主封面必须 `4:3`（`horizontal4x3Path`），个人空间伴随版必须 `16:9`（`horizontal16x9Path`），两者缺一不可。
   - **YouTube**：仅需 `16:9` 横版封面（`horizontal16x9Path`）。
   - **X (Twitter)**：由 `xTwitter.tweets` 承载单条或双条 Thread 文案，交由 `ego-browser` 配视频发出。
3. **草稿先验与安全门禁**：统一通过 `scripts/distribute.py <工程目录> --check-only` 先跑通全平台校验；确认无误且完成 `video-publisher` 账号 onboarding 后再加 `--run` 上传并填完表单，**默认一律停在最终发布按钮前的 READY 草稿态**，未经人工明确放行绝不触发最终发布。
4. **飞书回写闭环**：分发或成片导出后可带 `--sync-feishu`（或单独运行 `scripts/feishu_sync.py <工程目录> --sync-platforms`）自动扫描 `delivery/`、`output/`、`edit_*/*成片*.mp4` 并回写飞书总表，同时把各平台的实际标题/短标题、定时时间、封面与卡点明细自动同步至「分平台分发与数据明细」子表（支持优先读取 `preflight_report.json` 或自动合并 `~/.video-publisher/v2-jobs/*/state.json`）。

## 五、 后续演进与待精进专项（V2 Backlog）

1. **🎨 封面视觉升级专项（优先级高）**：
   - **当前现状**：当前流程主要依托视频抽帧画面直接叠加信息卡片（`3:4` / `9:16` / `4:3` / `16:9`），人物与背景层次分离不足、视觉冲突感和吸睛力有限；
   - **待优化方向**：后续需专项核实并升级封面生产链路——重点打磨高精度人物抠像、背景降噪与景深对比、视觉隐喻道具/对比图卡片排版、以及面向不同平台点击心智（小红书大字痛点、YouTube Shorts 首帧强聚焦、B站悬念反差）的差异化模板体系。
2. **📊 T+3 天发后数据原行回写（第二步规划）**：
   - 在已建好的「分平台分发与数据明细」子表后半段（播放量、点赞、收藏、评论、前2秒跳出率、5秒完播率、复盘诊断结论），结合首批真实发布数据打通 `review.py --sync-feishu` 按「选题 + 平台」原行回写并汇总主表总播放。
