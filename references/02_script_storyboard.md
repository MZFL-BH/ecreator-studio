# 02 脚本与分镜抗压参考指南

## 一、 黄金 3 秒（Hook）五大开场范式
1. **下结论/亮态度**：开门见山直接扔结论，不作铺垫（“千万别再用 XX 了，纯属交智商税”）。
2. **反向提问/戳痛点**：“你是不是也经常剪视频剪到凌晨，播放量却不过百？”
3. **视觉/动作前置**：视频开头 1 秒立刻出现特写、突发动作或反常画面，绝不用静止半身中景开头。
4. **悬念留白**：“如果我告诉你，这个方法能帮你每天省下 2 小时，你敢信吗？”
5. **数字量化**：“从 0 到 10 万播放，我只做对了这 3 件事”。

## 二、 短视频标准四列分镜模板

拍摄前必须将台词转化为具有执行力的四列表格：

| 时间戳 | 景别与画面动作 | 台词 / 口播文案 | 音效与情绪引导 |
| :--- | :--- | :--- | :--- |
| **00:00 - 00:03** | 【特写】手机屏幕快速划走画面，镜头快速推近主角挑眉 | “别划走！如果你也在做自媒体，这段可能救你的命。” | 【音效】急促划屏嗖声 + 警报音<br>【情绪】紧张、好奇 |
| **00:03 - 00:15** | 【中景】主角坐下，指向身后的白板（白板写核心痛点） | “大多数人完播率低，不是你讲得不好，而是开头废话太多。” | 【音效】转场顿音<br>【BGM】轻快节奏鼓点淡入 |
| **00:15 - 00:45** | 【特写切客体】展示电脑端自动化剪辑工具运作界面 | “今天教你用一个脚本，直接切掉所有气口，省下一半时间。” | 【音效】鼠标点击清脆声 |
| **00:45 - 01:00** | 【全景/中景】主角直视镜头总结，做出互动手势 | “具体脚本已打包，评论区扣 666，带走直接跑。” | 【BGM】高潮上扬收尾 |

## 三、 开拍前强制动作：Writer × Viewer 双角交叉对练（5~8 分钟）

写死长逐字稿之前，必须由创作者与 Agent 交叉扮演**「作家」**和**「5秒划走的挑剔路人」**：
- **自有实操题**：作者先口述核心干货，Agent 扮演“只想明天抄作业的路人”挑刺并逼出必须录屏的真镜头；
- **外网转化/卡壳题**：Agent 先出 2~3 个切角骨架，作者扮演目标观众枪毙空话与假痛点。

演观众的一方握有三票否决权：
1. **前 5 秒留存红线**：严禁“哈喽大家好”“这期跟大家讲一下”等寒暄，第 0~5 秒必须出现“具体对象 + 痛点/量化结果”及真视觉证据；
2. **Before / After 实机证据**：口述“更好用/解决了幻觉”不算过关，必须先锁定要提前录好哪 2~3 个真实操作/报错前后反差画面（隐藏浏览器书签栏、系统菜单栏，严禁把提词用导播网页直接当正片放）；
3. **单一爽点做减法**：每条 1.5~2.5 分钟只让观众带走 1 个核心动作或认知突破（450~600 字），多余支线直接砍掉拆下期。

## 四、 随脚本同步锁定的「发前 2 分钟盲测验收单 (Pre-Release Gate)」

在正式敲定 `script.md` 时，必须把发前复核标准同步写死在脚本顶部（而不是剪完再凭感觉看），多平台分发前按此 4 条盲测放行：
1. **首帧与画面洁净度**：`0s`、`3s`、`15s`、`45s` 抽帧不得出现本地 `file://` 路径、浏览器杂乱书签栏或密密麻麻的提词导播网页；
2. **前 15 秒字幕 Hook**：抽前 15 秒 `.srt` 盲读，必须已明确点出主题对象与核心冲突/收益结果；
3. **承诺证据兑现**：脚本约定的 Before/After 实机画面或对比证物，必须在成片前 60 秒内真实露脸；
4. **时长与节奏密度**：成片落在目标时长红线内（默认 `90s–180s`），无大段口癖注水拖长。
